# Student Marksheet Web Page

## Overview

This project is a responsive HTML and CSS-based student marksheet template designed to display academic performance in a structured and professional format. The webpage presents student details, subject-wise marks, grades, overall percentage, rank, and pass/fail status using well-organized tables and color-coded sections.

## Features

- School information header
- Student profile section
- Subject-wise marks table
- Theory and internal assessment breakdown
- Grade calculation display
- Total marks and percentage summary
- Academic grade and rank information
- Pass/Fail status notification
- Color-coded marks visualization
- Clean and easy-to-read layout

## Technologies Used

- HTML5
- CSS3

1. Download or clone the project.
2. Ensure both `index.html` and `marksheet.css` are in the same folder.
3. Open `index.html` in any modern web browser.
